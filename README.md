# Almond Docker images

> [!NOTE]
> The [Almond](https://github.com/almond-sh/almond) Docker images are now managed from the
> [main Almond repository](https://github.com/almond-sh/almond) (see its
> [`Dockerfile`](https://github.com/almond-sh/almond/blob/main/Dockerfile)).
> This repository is no longer used to build them.
>
> See the [Docker page](https://almond.sh/docs/try-docker) of the Almond documentation
> for more details on how to use them.

Images are published on Docker Hub as [`almondsh/almond`](https://hub.docker.com/r/almondsh/almond).
